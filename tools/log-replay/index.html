🔥 DevTools Console Log Replayer

Replay browser logs directly into DevTools console with native formatting

or drag and drop a .json replay file here

📋 Instructions

1. Open DevTools (F12) → Settings (gear icon) → Console → Enable "Custom formatters"

2. Go to the Console tab

3. Load a browser replay log file (.json format)

4. Click "Start Replay" to see logs appear in the console

5. Use DevTools level filters (Errors, Warnings, Info, Verbose) to filter logs

⚙️ Required: Enable Custom Formatters

For proper log rendering with collapsible details AND level filtering:

DevTools → Settings (⚙️) → Preferences → Console → ✅ Enable custom formatters
