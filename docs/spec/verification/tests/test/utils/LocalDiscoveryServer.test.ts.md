## Overview

These component cases run real loopback discovery and real authenticated `P2PManager` instances. They compare
transport identities across an explicit raw close, prove that close does not blacklist the remote identity,
then observe the same topic after leave or explicit blacklist. The tests
exercise the production session, canonical dialer, retry timer, handshake, and blacklist checks; no synthetic
transport or precomputed result boolean stands in for discovery.

Two cases drive a one-sided reconnect suspension across the pair, with the suspending side chosen by real
address order rather than by index. Placing it on the canonical dialer stops that side's loop, and the case
counts handshakes on that same side, so a further handshake can only have come from the peer taking the dial
over; the suspension then still refuses it, leaving no transport token and the suspension intact. Placing it
on the other side instead leaves the canonical dialer redialing into a refusal it is never told about, and
the case holds one full agreement window after the first redial before reading both peers' standings — the
oracle is that neither identity is excluded, so a refusal does not become an exclusion on the refused peer
and a suspension does not escalate on the suspending one.
