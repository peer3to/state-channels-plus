## Overview

These component cases run real loopback discovery and real authenticated `P2PManager` instances. They compare
transport identities across an explicit raw close, prove that close does not blacklist the remote identity,
then observe the same topic after leave or explicit blacklist. The tests
exercise the production session, canonical dialer, retry timer, handshake, and blacklist checks; no synthetic
transport or precomputed result boolean stands in for discovery.

Two cases drive a one-sided reconnect suspension across the pair, with the suspending side chosen by real
address order rather than by index. The first places it on the canonical dialer, the side that owns the
pair's only dial loop, and counts that side's own handshake starts after its close: the count rises while the
suspension stands, proving the ban never stopped a dial, and the transport token stays `null` through one
full agreement window, proving every one of those dials was refused at admission without excluding anyone.
Lifting the suspension on that same side then produces a transport again with no dial-back call anywhere —
the retry loop that never stopped is simply admitted. The second places the suspension on the other side
instead, leaving the canonical dialer redialing into a refusal it is never told about, and holds one full
agreement window after the first redial before reading both peers' standings — the oracle is that neither
identity is excluded, so a refusal does not become an exclusion on the refused peer and a suspension does not
escalate on the suspending one.
