## Overview

Exercises the public component behavior listed below with real contract or runtime state. Every seeded JOIN moves the chain's inbound head, and every upload anchors at that head. The anchor cases seed a head block whose predecessor is `consumed` and upload in both modes anchored at each: `consumed` reverts `RaceConditionDisputeInboundNotLatest(head, consumed)` with no admission-state change, the head creates the window with one commitment. Height is left at zero on both sides, so a head hash with a wrong height is not exercised.
