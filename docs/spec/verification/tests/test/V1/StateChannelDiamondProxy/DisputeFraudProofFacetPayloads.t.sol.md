## Overview

In the first contract, five Foundry component tests pin the operands the dispute race-condition reverts carry, so a
payload that names the right error with the wrong values fails. Three drive the deployed diamond
(`DiamondHarness`); two drive `TimeoutTooEarlyPayloadHarness`, a test-only contract that inherits
`DisputeFraudProofFacet` and `UtilityFacet` and exposes the internal `_handleTimeoutTooEarly`
handler plus a single block-calldata-commitment seed — the production handler body still runs.

The first opens a channel, uploads a dispute so the evidence window opens at a known absolute
timestamp, then warps strictly past the window's evidence period and uploads a second dispute from
the other participant; the revert must name the period end computed from the first upload and the
later current timestamp as two different values. The second and fourth build a genesis snapshot
whose `originForkId` is a distinct constant and derive the claimed fork as the hash of that
snapshot data, with no dispute window on the origin fork and no matching on-chain snapshot, so the
chain cannot date the genesis; both timeout-proof pipelines — the `TimeoutTooEarly` handler and
the routed `validateTimeoutCalldataPostedProof` — must name channel, origin fork and target fork,
three mutually distinct hashes asserted distinct in the test. The third and fifth put a previous
block's calldata commitment on chain (seeded on the harness, and posted through the diamond's real
`postBlockCalldata` for the routed case) while the proof denies any on-chain timestamp for it; the
revert must carry that previous block's fork, height, author and stored commitment, each different
from the timed-out block's corresponding value, so a payload built from the wrong block fails.

A second contract, `DisputeStateProofBelowOnChainAnchorTest`, runs on the shared `StateProofStaging`
harness and applies the `DisputeStateProofBelowOnChainAnchor` dispute fraud proof through
`applyDisputeFraudProofs` on a committed dispute. With a same-fork normal on-chain snapshot at
height 5, a posted-data dispute whose latest block is 3 is killed, and a dispute whose latest block
is 5 is not. With the fork genesis on chain, an empty proof is not countered; with a normal
snapshot at height 0 (block 0 committed it), an empty proof is below it and is killed. The
harness reads the anchor from storage; no newer disputer-signed block is supplied.

The below-anchor counter is also rejected when the dispute's latest block is above the same-fork
snapshot height, and when the on-chain snapshot lies on another fork.

A third contract, `DisputeInvalidStateProofFinalizedStateTest`, on the same staging with the fork genesis on
chain, commits A's posted-data dispute over the threshold run [2, 3, 4] and applies `DisputeInvalidStateProof`
with the dispute's own auditing data. When the posted finalized state is the state of block 4's snapshot instead
of the state of the threshold snapshot at 2 where the walk ends, the dispute is killed and A is slashed; when it
is the walk's finalized state, the allegation is rejected: the dispute stays, A is not slashed and the submitter
is.

A fourth contract, `DisputeFraudProofFamilyTest`, on the same staging, drives each family through
`applyDisputeFraudProofs`. A table gives every family a valid allegation and its invalid
counterpart against a fresh harness: `DisputeNotLatestState`, `DisputeInvalidOutputState`,
`TimeoutThreshold`, `TimeoutNotLinkedToLatestState`, `TimeoutParticipantNotNext`,
`DisputeLastMilestoneNotFinalAndNoAuditingData`, `InvalidDisputeReason` and
`DisputeInboundHashNotInChain`. A valid allegation kills the dispute and slashes the disputer; an
invalid one leaves the dispute committed and slashes the submitter. `DisputeOnChainSlashesNotSubset`
kills a dispute that lists an unrecorded slash and reverts as a race on a subset. A valid kill
reverts at the kill-period end and is accepted one second before it. A batch that repeats a valid
kill skips the second proof, and a later invalid allegation against the killed dispute costs the
submitter nothing.
