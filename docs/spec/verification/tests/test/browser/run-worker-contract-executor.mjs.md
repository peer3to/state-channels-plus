## Overview

Eight named Node test declarations drive the existing browser page in Chromium: performance metadata, contract execution, adjusted clock, detached failures, main-thread WebRTC, dedicated-worker transfer and dedicated-worker proxy. Each declaration runs its real browser execution and assertions. Shared setup and browser-error checks remain common. No shared Node unit suite is duplicated. An eighth declaration runs the crash-log smoke against the repo's real receiver on a fresh directory: a vm worker beneath the main realm crashes on a timer and collects on its own, then `logger.uploadLogs` runs a collection over the worker port; the round reports both realms ok, and the server holds a `vm` chunk and a `main` chunk carrying the marker under the main realm's identity.
