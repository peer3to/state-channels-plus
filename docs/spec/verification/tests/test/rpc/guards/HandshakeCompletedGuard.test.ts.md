profiles, a real service, and controlled handshake completion. The request-during-negotiation
case pins current behavior only: it sends through the real pending-request correlation path and
proves the immediate error settles the caller before the later replay response is ignored, as recorded in
the source report's Specification contradictions section and [`OQ-34-FY08V2`](../../../../../specification/open-questions.md#oq-34-fy08v2). A passing test does not claim conformance for that behavior.
