## Overview

The suite drives the local balance-invariant audit on a channel opened with nonzero genesis
deposits. The honest case proves that local replay preserves the finalized deposit total and
accepts the dispute without storing a fraud proof. The tampered case increments only
`totalDeposits.amount`, updates the committed hashes and signatures, and proves that honest peers
store `DisputeInvalidBalanceInvariant`, kill the invalid dispute, and resolve the successor fork.
