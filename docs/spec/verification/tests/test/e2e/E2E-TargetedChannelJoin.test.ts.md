The suite contains 31 direct literal cases. It drives unopened preflight, targeted matching, opening,
authoritative-open handoff, exact-channel sync, requested membership, cancellation, matcher-only timeout,
explicit retry, caller-owned initial synchronization failure, transport preservation, and host-local policy.

## Result boundary

Observer calls finish at `SYNCED`. Membership calls finish at confirmed genesis participation or
receipt-confirmed `PENDING_PARTICIPANT`/`PARTICIPATING`. Initial-load failure disposes the uncommitted
runtime; later pending or participating failures preserve it. The suite does not use teardown to stop a
feature operation.
