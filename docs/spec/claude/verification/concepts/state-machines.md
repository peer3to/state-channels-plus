## Verification overview

**Status:** Incomplete; exact evidence exists for several author-validation, join, transition-failure,
and dispute workflows, but most required permutations remain unmapped or only indirectly exercised.

### Specification-test adherence

Current tests partially establish next-writer enforcement, successful repeated transitions, new-member
join processing, retry behavior, transition rejection, and wrong-turn dispute outcomes. They do not
yet establish the full specification plan: arbitrary integrator replay equivalence, all state shapes,
prohibited ambient context, canonical custom serialization, mapping enumeration, custom balance
algebras, all author/path combinations, or removal/slashing equivalence.

### Implementation-test adherence

The strongest implementation evidence is around `ValidationService`, concrete Math-state-machine join
and transition flows, and on-chain dispute handling. Most file-owned `UNIT-TEST-SM-*` and composed
`INTEGRATION-TEST-SM-*` permutations have no exact declaration mapped. In particular, no dedicated
tests establish `AStateMachine` orchestration and wrapper atomicity, the complete EVM adapter surface,
`peekNextToWrite` failure cleanup, or the complete balance API.

### Contradictions

No inspected test has an oracle that demonstrates behavior opposite to its intended case. The prior
verification page did, however, overstate broad file links as evidence. For example, Block and
StateSnapshot codec tests do not prove an integrator state machine's `getState`/`setState` inverse,
and timeout or dispute-reduction tests do not prove the base removal/slashing wrapper symmetry.
Those tests are now treated as adjacent coverage rather than credited to cases they do not exercise.

One important limitation remains explicit: the on-chain wrong-turn test uses `MathStateMachine`,
which has its own next-writer guard. It therefore does not prove the specification case requiring
generic on-chain enforcement for a state machine without an in-contract guard.

### Missing

- A reusable cross-runtime replay-equivalence suite covering every public transition, success/revert,
  state shape, outbound-message cardinality, and repetition.
- Direct state-machine codec tests for valid and malformed states, including canonical ordering and
  deterministic mapping enumeration.
- Static and executable checks for every prohibited ambient EVM input and `_tx.body` use.
- Property tests for simple and custom balance algebras, including underflow, overflow, canonical
  custom data, aggregate conservation, and retry after rejection.
- Complete correct/wrong/missing/duplicate/non-member author coverage across live, stored,
  spectating, calldata-dispute, and non-calldata-dispute paths using a state machine without its own
  author guard.
- Direct base-wrapper tests comparing removal and slashing success, failure, retry, concurrent
  membership changes, and outbound processing.
- Exact evidence for all remaining implementation unit and integration permutations in the bottom
  matrix.
