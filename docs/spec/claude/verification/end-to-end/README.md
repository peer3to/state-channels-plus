# End To End Level Index

> **Navigational index — not an evidence store.** The authoritative evidence units are the
> mirrored test reports under [../tests/](../tests/); each *declaration* there carries its level
> classification. This index never duplicates evidence.

**End-To-End** declarations exercise an externally observable protocol workflow across the relevant peers, contracts, chain, consumer, or runtime boundaries.

The generated, always-current declaration/level join is
[generated/traceability.md](../../generated/traceability.md) (Mapped test declarations). Until the
repository `test/` tree is physically reorganized by level (future work), the mirrored report path
follows the repository exactly and the per-declaration classification provides the normalized view.
