## Responsibility and observable boundary

The shared base every facet inherits: storage access, slash-set maintenance (append + queries up
to timestamp), pending-participant derivation by walking unconsumed inbound JOINs, inbound/
outbound chain verification and application, snapshot/block linkage predicates, dispute-window
commitment helpers (which look the window up by the shared
[`_disputeCommitmentHash`](./utils/DisputeUtils.sol.md)), threshold-set derivation,
`canParticipateInDisputes`, block authenticity, and
the enumerable open-channel append/removal helpers, the one state-proof walk and its start
([`_walkStateProof`](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L650), [`_getAnchorSnapshot`](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L438)), and the channel-open and fork-disputed predicates
([`_isChannelOpen`](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L207),
[`_isForkDisputed`](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L213)).

Every member is `internal`, so nothing here appears in a facet's ABI; each body is
dead-code-eliminated into the facets that actually call it. Compiled standalone the contract is
58 deployed bytes.

## Key design decisions

Current upload eligibility is the snapshot participant set plus JOINs after its inbound boundary through the latest inbound head, minus on-chain slashes. The lower boundary is excluded and the head included. Historical proof derivation explicitly keeps the zero stop hash; bounding current upload rights does not change historical thresholds. See [StateChannelCommon.sol](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L570).

1. **Shared-validation-by-inheritance:** one implementation of every multi-path predicate, which is
   the mechanism for [`REQ-CONTRACT-ARCH-2-BE651C` (Shared validation)](../../../../../specification/enforcement/contracts.md#req-contract-arch-2-be651c). Everything is `internal`, so a predicate's code is
   compiled only into the facets that call it (the stateless pieces that need no inherited storage
   keep moving to the free functions in [utils/](./utils/README.md)).
2. **The base binds `UtilityFacetInterface`, not the concrete facet.**
   [UtilityFacet](./UtilityFacet.sol.md) now derives from this contract so its delegatecalled views
   see the manager layout, which makes naming the concrete type here circular. The base casts
   `utilityFacetAddress` to the abstract [UtilityFacetInterface](./UtilityFacetInterface.sol.md)
   instead ([#L11](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L11),
   [#L65](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L65)).
   The calls themselves are unchanged plain `CALL`s to the same deployed helpers. One pre-existing
   exception remains: `_getGenesisTimestamp` reaches the same `pure`
   `isGenesisSnapshotWithoutTimeCheck` two different ways — through the diamond at
   [#L85](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L85)
   and directly on the facet at
   [#L102](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L102).
   Same verdict either way; the first path costs an extra self-CALL plus a routed delegatecall
   (see the [architecture view](../../../../views/architecture/contracts/manager-and-facets.md) §4.8).
3. **`_isChannelOpen` and `_isForkDisputed` live here, not on the proxy.** Both were public views on
   [StateChannelManagerProxy](./StateChannelManagerProxy.sol.md); their bodies moved down verbatim so
   that `open` and [JoinChannelFacet](./JoinChannelFacet.sol.md) can evaluate them as internal calls
   while the external `isChannelOpen`/`isForkDisputed` selectors route to
   [UtilityFacet](./UtilityFacet.sol.md)
   ([#L207](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L207)).
   `JoinChannelFacet` previously reached `isForkDisputed` by an external self-call; it now calls the
   internal directly, which removes a call frame from the join path.
   Block authenticity follows the same pattern with no external selector at all: `_isBlockAuthentic`
   ([#L333](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L333))
   decodes through `tryDecodeBlock` and recovers the author with `retrieveSignerAddress`, and only the
   fraud-proof and state-proof facets call it. The former public `UtilityFacet.isBlockAuthentic`
   wrapper and its route are removed; the client checks author signatures itself under the
   signature carve-out of [`INV-MIRROR-1-VAF778` (Single implementation)](../../../../../specification/enforcement/local-mirror.md#inv-mirror-1-vaf778);
   `_isBlockAuthentic` is not `virtual`: no deployment overrides it, the local mirror included.
4. **Pending means unconsumed.** `_getPendingParticipants` walks the inbound chain from the channel's
   head down to the current snapshot's own inbound hash, so it names only the joins the snapshot has not
   applied. The earlier unbounded walk counted every JOIN ever recorded, including the original
   participants' open joins: a leaver stayed "pending" after its reduction and a slashed inbound joiner
   stayed in the eligibility set ([cross-layer-messages.md](../../../../../specification/settlement/cross-layer-messages.md)).
   Two readers keep the unbounded walk: `reduce` for slash eligibility, because after a reduction is
   mined the snapshot lists only the survivors and a late reducer must still fold the same slashes
   ([DisputeVerificationFacet.sol.md](DisputeVerificationFacet.sol.md)), and the milestone-finality
   read in [DisputeFraudProofFacet.sol.md](DisputeFraudProofFacet.sol.md) for its historical joiners.
   That read takes the chain snapshot participants, which no adoption can change while a proof against the
   dispute can land ([StateSnapshotFacet.sol.md](StateSnapshotFacet.sol.md)), and subtracts only the slashes
   the dispute commits, never the live slash set.
5. **The rejected inbound replay names the state it was seeded with.**
   `_processInboundMessages` walks every message on the state already loaded in the state machine
   (the caller loaded `encodedStateMachineState`, or the transition left it loaded); when a message is refused it raises
   `ErrorDisputeStateMachineInboundProcessingFailed(blockIndex, messageIndex, participant, messageType, stateMachineStateHash)`
   ([#L523](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L523)).
   The two indices locate the message but not the input it was applied to, and the same message can
   be valid or invalid depending on the seed state, so the seed's hash is what makes a rejected
   replay reproducible. It is `if (!success) revert`, not `require`: the hash is over the whole
   encoded state, and eager argument evaluation inside `require` would pay for it on every message
   of every successful walk.
6. **The reduced-result commit names a missing window before it names a deadline.**
   `_commitToDisputeReducedResult` checks window existence first
   ([#L624](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L624)),
   because `_isKillPeriodExpired` derives its deadline from a zero
   `lastEvidenceSubmissionTimestamp` when no window was created and would report a deadline that
   reads as long past for a call refused precisely because nothing has expired. Every production
   caller creates the window or checks it first, so this is defence in depth for a future caller,
   not a reachable path today. Written as `if (!…) revert` rather than inside `require` because
   the operand `disputeWindow.forkId` is a storage read the condition itself does not perform, and
   error arguments are evaluated eagerly.

7. **The anchor has one owner here.** `_getAnchorSnapshot` ([#L438](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L438)) returns the stored snapshot and `canUseOnChainSnapshot`, which `_canStartFromOnChainSnapshot` ([#L449](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L449)) sets when the snapshot is on the asked fork and is not that fork's genesis ([#L450](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L450)–[#L451](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L451)). The genesis is excluded because no block commits to it: block 0 only links back to it through `previousBlockHash`, so no run can hold it as a start block. It is recognized by its data at height 0, because the fork ID is the hash of the genesis snapshot data; a height test alone is ambiguous, since the snapshot that block 0 commits also has height 0. When the anchor is not usable the proof starts at the fork genesis. Why here: the walk, the dispute fraud proofs ([DisputeFraudProofFacet](./DisputeFraudProofFacet.sol.md)), and the public `getAnchorSnapshot` and `isBlockChallengeEligible` ([StateProofFacet](./StateProofFacet.sol.md)) all read it, and one internal keeps them from diverging ([`REQ-SP-8-9PK9TS`](../../../../../specification/disputes/dispute-processing.md#req-sp-8-9pk9ts)).
8. **One canonical walk.** `_walkStateProof(input, start, checkFinality)` ([#L650](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L650)) is the only state-proof walk. [StateProofFacet](./StateProofFacet.sol.md) calls it from the stored snapshot (`verifyMilestones`, `isStateProofLinked`), and [LocalDiamond](./LocalDiamond.sol.md) calls it from a supplied start (`verifyMilestonesFromTrustedStart`). It returns a `ProofWalkResult`; when `valid` is false no other field is usable. Its rules, in order:
    - **Evidence count.** With finality, the milestone and milestone-snapshot counts must match ([#L658](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L658)).
    - **Genesis start and empty proof.** When the start is not a usable anchor, or the proof is empty, `_getGenesisSnapshot` ([#L755](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L755)) returns `(isLinked, hasTimestamp, genesisSnapshot)` ([#L663](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L663)). When the start snapshot is this fork's genesis, it is the genesis and the input genesis data is not read ([#L760](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L760)–[#L761](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L761)). Otherwise the fork genesis is not on chain (the stored snapshot is on another fork, or it is a usable anchor and the proof is empty): the input genesis data must hash to the fork ID ([#L763](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L763)) and the genesis is dated through the origin fork's window (also for a reduced fork the chain has not adopted). An unlinked genesis makes the walk invalid ([#L664](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L664)); only an empty proof may skip the date ([#L666](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L666)). Why: the genesis data is checked only where the walk uses it, so a proof from the on-chain genesis or from a usable anchor needs no genesis data. An empty proof is the fork genesis even when a normal on-chain snapshot exists.
    - **Required blocks.** Every milestone is nonempty and its first and last blocks decode on the input channel and fork (`_tryDecodeRequiredBlock`, [#L737](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L737)).
    - **Order.** First heights must not decrease ([#L681](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L681)); overlap is allowed.
    - **Dropped milestones.** A milestone whose last block is below the start height is dropped: it awards no finality and its inner blocks and snapshot entry are never read ([#L685](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L685)). Why: the start is final, so history below it is not needed, and a peer that installed the fork from it holds nothing older.
    - **Start run.** With an on-chain start, a milestone whose first height is at or below the start height must hold the start: the block at offset `start.blockHeight - firstHeight` exists, has that height, and commits the start's hash ([#L689](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L689)..[#L694](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L694)). The run links from that offset only ([#L696](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L696)), needs no threshold, and `replayBlockIndex` becomes the offset + 1. The rule binds the state after that block, not the block's identity: no hash of the block that committed the snapshot is stored.
    - **Genesis block 0.** With a genesis start, a first block at height 0 must link to the genesis snapshot through `previousBlockHash` ([#L704](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L704)); that link alone does not finalize it.
    - **Union threshold.** Every other kept milestone proves its first block by the union of the last verified set, the resulting set, and the JOINs in the inbound interval between the two snapshots (`_deriveMilestoneUnionParticipants`, [#L773](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L773)), and that first block must commit the supplied milestone snapshot ([#L720](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L720)–[#L721](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L721)). A final hop advances `finalizedSnapshot`, and `replayBlockIndex` becomes 1. On-chain slashes are never subtracted here, so a past proof keeps its validity after a later slash ([`REQ-SP-3-SP1JG4`](../../../../../specification/disputes/state-proofs.md#req-sp-3-sp1jg4)).
    - **Unfinal block 0.** A hop that is not final is invalid, except a genesis block 0 that is the only milestone: then the whole run is the unfinal tail and replay starts at 0 ([#L725](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L725)).
    - **Linkage-only mode.** With `checkFinality` false the walk reads no milestone snapshots and counts no threshold ([#L717](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L717)); only `valid` is usable.
    - **Replay position.** `replayBlockIndex` is set per milestone, so the last milestone's value is the result: its length for a dropped milestone or a start block at its end (no tail), the offset + 1 after the start block, 1 after a final first block, and 0 for a sole unfinal genesis block 0 ([#L683](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L683), [#L698](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L698), [#L724](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L724), [#L727](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L727)). An empty proof leaves it 0. `replayBlockIndex` equal to the last milestone's length means no tail.
9. **One run walker.** `_walkMilestoneBlocks` ([#L802](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L802)) checks every block from an index: it decodes and is on the fork, keeps the run's channel, links to its predecessor by `keccak256(encodedBlock)` and height + 1, and carries its author's signature; it counts each expected signer once among authors and confirmation signers (`_tryInsertAddressInThresholdSet`, [#L870](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L870)), so duplicates and outsiders never complete a threshold ([`REQ-ENFPROOF-2-YZDCXM` (Deduplicated threshold counting)](../../../../../specification/enforcement/proof-verification.md#req-enfproof-2-yzdcxm)). `_isNextHeight` ([#L865](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L865)) rejects a height that would wrap at the maximum. [StateProofFacet](./StateProofFacet.sol.md) `isMilestoneFinal` reuses this walker. The walker has no gas bound (the open `TODO` at [#L808](../../../../../../../contracts/V1/StateChannelDiamondProxy/StateChannelCommon.sol#L808)).

## Assumptions, dependencies, trust boundaries, and limits

- Inherited-layout discipline (facets stateless) is what keeps `delegatecall` sound.
- The helpers reached through `UtilityFacetInterface` are plain `CALL`s: they run in the utility
  facet's own storage context and must stay `pure`/`view`. Nothing verifies at run time that the
  code at `utilityFacetAddress` implements the interface — that is a deployment commitment.
- Keeping every member `internal` is load-bearing for the size budget: a `public` member here would
  compile its body and dispatcher entry into every facet.

## Specification adherence

- Identical predicate semantics on every path by construction; append-only slash set with timestamps ([`INV-ENFFP-1-BGVZN4` (Slash set integrity)](../../../../../specification/enforcement/fraud-slashing.md#inv-enffp-1-bgvzn4) storage half).

## Specification contradictions

None demonstrated.

## Missing behavior

The size-reduction decomposition of the shared base — moving predicates that need no inherited
storage into free-function libraries — is still architecture future work; the base's `internal`
bodies are still inlined into each calling facet.
