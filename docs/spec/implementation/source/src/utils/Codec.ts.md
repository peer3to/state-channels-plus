## Responsibility and observable boundary

The canonical struct codec: ABI encode/decode against the canonical ethers type strings for every
protocol struct, fraud proof, dispute fraud proof, and sync payload. It also decodes arbitrary EVM
return values and recursively converts ethers Results to plain objects across module graphs.

## Key design decisions

1. **One codec for all protocol structs** — a second encoding path would fork the signature domain; every encoded\* wire field passes through here.
2. **Type strings are the schema commitment:** adding/altering a struct is a protocol-visible change, not a refactor.
3. **Decoded ethers values are identified by their public Result API.** Recursive conversion works
   across compatible ethers copies in separate production chunks; constructor identity is not part
   of the serialization contract.

## Inputs, outputs, state, and side effects

| Aspect       | Contents                                                                               |
| ------------ | -------------------------------------------------------------------------------------- |
| Inputs       | Protocol structs and schema enums; encoded bytes; EVM return bytes and an ethers type. |
| Outputs      | Canonical ABI bytes, decoded structs/primitives, and plain Result projections.         |
| Owned state  | Parsed ABI-type caches keyed by protocol enum or EVM type string.                      |
| Side effects | None beyond cache population and contextual errors for invalid encode input.           |
