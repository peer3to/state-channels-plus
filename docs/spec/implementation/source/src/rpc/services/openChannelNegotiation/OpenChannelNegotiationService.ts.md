## Responsibility and observable boundary

The default-root negotiation engine accepts only a committed lobby transcript. It derives and
sets the channel ID locally, admits RPCs only for the committed peer/attempt/challenges, lets the
lower address initiate and first-sign, lets the higher address validate, co-sign, and submit, and observes
the accepted chain-open event before declaring completion. It owns unsigned failure cleanup and
signed-attempt retention through chain open or payload expiry.

## Key design decisions

1. **Re-derive, never adopt.** The proposal is compared field-for-field against a locally rebuilt struct with the local amount — term substitution is structurally impossible to sign ([`INV-NEG-1-6FW90P`](../../../../../../specification/peer-communication/channel-negotiation.md#inv-neg-1-6fw90p)).
2. **Deterministic split by address order** removes glare and a redundant round trip. The lower address proposes and first-signs; the higher address validates, co-signs, and directly submits the exact payload ([`REQ-NEG-1-RTKPT1`](../../../../../../specification/peer-communication/channel-negotiation.md#req-neg-1-rtkpt1)).
3. **Success only from the canonical chain-event path.** Each attempt subscribes to the typed,
   completed `EventHandler.onChannelOpened` notification. The existing `StateChannelEventListener`
   and `EventSyncService` remain the only owners of ethers filtering, replay, deduplication, and
   ordering. Attempt cleanup removes the internal subscription. The expiry check still polls chain
   state, and no peer message confirms an opening
   ([`REQ-NEG-2-ED48TZ`](../../../../../../specification/peer-communication/channel-negotiation.md#req-neg-2-ed48tz)).
4. **Cold proposals refused:** no negotiated amount → punish, blocking validation against default balances.
5. **Role-specific submission accountability:** a higher peer's local send failure does not blame the lower proposer. Both signed attempts wait for chain evidence; only the lower peer excludes the higher submitter if the deadline expires without an open. Runtime disposal settles even a signed local wait as cancelled because no runtime remains to observe it.

## Targeted connect contribution

Initialization returns the exact attempt's `NegotiationOutcome` directly and stores ordinary versus targeted
mode. Terms use full encoded balances validated with the state-machine zero and lesser-than operation.
Ordinary derived-ID failures clear selection and keep ordinary retry policy. Targeted unsigned failure clears
only attempt-local work and retains the target/listener. Authoritative fixed-target open produces one
no-blacklist handoff, including the post-sign no-submission guard and targeted receipt-race reclassification.
No matcher cleanup or `timeoutMs` enters this service.

Observed target-open classification is retained on the active attempt. If signing completes after the event,
submission waits for participant lookup and rechecks the handoff. A targeted handoff submits no opening
transaction; the existing contract-level already-open recovery still covers the final race.
