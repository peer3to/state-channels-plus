## Responsibility and observable boundary

One canonical source-to-signatures map records spent contributions.

## Key design decisions

Network source keys use the existing checksum-address helper. Equivalent address casing spends one source allowance. When a fresh queued entry exists during restore, its admitted values retain priority over that source’s older dequeued values; other sources keep independent allowances.

`BlockOrigin` names network, calldata and proof origins. The options type requires a sender for network copies; internal callers supply these typed options.

The entry has `sourcesToSignatures: Map<Address, Set<Signature>>`. [mergeEntry](../../../../../../src/storage/QueueStorage.ts#L130)
adds each source's distinct signatures until its N-value allowance is full, then drops extra values.
Other sources keep their own budgets. A repeated signature is charged once per supplier. The same
merge applies to creation, queued copies and restore; stored blocks use standalone entries.
Storage does no signature selection by encoding, normalization or recovery. Block owns representation
and timestamp merging; validation checks the admitted signatures. Dequeue and processing are unchanged.

## Inputs, outputs, state, and side effects

Explicit origin and source contributions enter through createEntry and queueBlock. Storage owns the
queued entries and coordinate index. Dequeue returns a QueuedBlockEntry; it performs no I/O, timers,
signer recovery, or processing lifecycle management. The Storage facade provides deep-copy boundaries.

## Assumptions, dependencies, trust boundaries, and limits

N bounds sources and supplied signatures for one queued network entry. Internal proof evidence uses its own validation bounds. Total hashes, channels, connection rate and repeated later lifetimes are not bounded here. Capacity does not imply misconduct. Membership churn never refunds a source slot.

## Specification adherence

The source implements the per-source contribution and dequeue portion of [`REQ-QSTORE-2-VYWJAQ` (Independent source allowances)](../../../../specification/storage/queue.md#req-qstore-2-vywjaq) and [`REQ-QSTORE-3-DEKYG6` (Queue scheduling)](../../../../specification/storage/queue.md#req-qstore-3-dekyg6). Transport eligibility and external work remain in BlockQueueManager.
