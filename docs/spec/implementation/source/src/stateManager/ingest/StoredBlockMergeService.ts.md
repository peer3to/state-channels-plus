## Responsibility and observable boundary

Merge incoming confirmations into an already-stored block under the caller's validation strategy.

## Key design decisions

Stored network copies arrive after the same eligibility and per-source allowance checks as fresh queue copies. Safe classification strips unrecoverable values through the strategy without dropping an otherwise valid stored block. Existing stored signatures are not attributed to the new supplier. Timestamp-only updates, duplicate results, finality notifications and valid growth retain their existing behavior. See [normalizeConfirmationSignatures](../../../../../../../src/stateManager/ingest/StoredBlockMergeService.ts#L44).

A copy brings something new only through a signer the stored block does not hold yet. [newSignerSignatures](../../../../../../../src/stateManager/ingest/StoredBlockMergeService.ts#L53) selects the first signature of each new signer, the copy is cut down to those, and a copy with none takes `noNewSignaturesOnExistingBlock`, so it is neither stored nor relayed. Repeated signatures of a held signer and author-recovering signatures are dropped silently, with no new strategy hook and no punishment; the strategy's growth hook stores and relays only the new signers ([`REQ-BLKSTORE-4-RQTR2Y` (One confirmation signature per signer)](../../../../../specification/storage/blocks.md#req-blkstore-4-rqtr2y)).

Defined timestamps write through storage.blocks.setOnChainTimestamp before signature handling. New-signer selection, participant-union checks and strategy hooks remain separate from Block's data-copy operations. See [StoredBlockMergeService.ts](../../../../../../../src/stateManager/ingest/StoredBlockMergeService.ts#L1).

## Inputs, outputs, state, and side effects

Merge incoming confirmations into an already-stored block under the caller's validation strategy. The caller schedules a QueuedBlockEntry under the ingress owner. This service relies on real stored snapshots and strategy-specific punishment/persistence. It returns undefined for absent blocks and checks the signature set again after a strategy strips outsiders.
